# Offline-First Lightweight EdTech LMS Engine (Prototype)

A zero-rated, text-first pedagogical content delivery and asynchronous synchronization engine designed for Ghanaian tertiary students facing electricity load shedding and cellular data tariff barriers.

## Author
BERNARD FIAGBENU (Computer Scientist)

## Target Problems Addressed
1. High cellular data costs that prevent students from streaming bandwidth-heavy video lectures.
2. Unreliable electrical grid connections and intermittent campus Wi-Fi.

## Running the Prototype
Requires Python 3.8+ (standard library only).

```bash
# Run demonstration
python3 offline_lms_engine.py

# Run test suite
python3 -m unittest test_lms.py
```
